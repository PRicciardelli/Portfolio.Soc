GL.iNet Security Lab

A custom OpenWRT-based wireless security platform for network segmentation, traffic inspection and isolated lab testing.

OpenWRT Networking VPN Firewall
01. Overview

Project Goal

The GL.iNet router was repurposed as a dedicated security lab gateway. The goal was to create an isolated network segment for wireless experiments while keeping the production network safe.

This project reinforced practical networking skills: VLANs, firewall zones, DNS filtering, VPN routing and wireless access point management.

Security First

The lab network is fully isolated from the home production network to prevent accidental impact.

Router Features

  • VLAN Segmentation
  • Firewall Zones
  • VPN Client/Server
  • DNS Filtering
  • Guest WiFi Lab
