Wazuh SIEM SOC Lab

A complete Security Operations Centre laboratory for real-time monitoring, attack simulation, log analysis and threat detection practice.

Wazuh SIEM Linux Windows Log Analysis Incident Response
01. Overview

Project Goal

This lab was built to replicate the core functions of a SOC environment. The objective was to deploy a centralised SIEM, collect logs from multiple endpoints, simulate realistic attacks, and practise alert triage, investigation and response.

The environment combines a Wazuh server with Windows and Linux agents, plus a Kali Linux attacker VM to generate malicious telemetry in a safe, isolated network.

Learning Outcome

Practical experience with SIEM architecture, agent deployment, Windows/Linux log analysis, custom rule creation and incident triage workflows.

Lab Components

  • Ubuntu Server 22.04
  • Wazuh Manager + Indexer
  • Wazuh Dashboard
  • Windows 10 Endpoint
  • Kali Linux Attacker
  • VMware Workstation
02. Components

Lab Infrastructure

Ubuntu Server 22.04

Host for the Wazuh manager, indexer and dashboard, providing centralised log storage and alerting.

Wazuh Manager

Collects, decodes and analyses security events from all agents using rules and decoders.

Wazuh Indexer

Stores and indexes incoming logs for fast searching, correlation and dashboard visualisation.

Wazuh Dashboard

Web interface for querying logs, reviewing alerts and creating custom security dashboards.

Windows 10 Endpoint

Monitored agent generating Windows Event Logs, Sysmon telemetry and file integrity alerts.

Kali Linux VM

Attacker platform used to run brute-force, reconnaissance and malware simulation exercises.

04. Attack Simulations

Scenarios Practised

01

Brute Force Attack

Simulated SSH and RDP brute-force attempts to generate authentication failure alerts and observe lockout behaviour.

02

Network Reconnaissance

Used Nmap and ping sweeps from Kali to trigger network discovery alerts and analyse scanning patterns.

03

Malware Test

Deployed safe, controlled malware samples (e.g. EICAR) to test file integrity monitoring and antivirus integration.

04

Privilege Escalation

Practised detecting suspicious command execution and permission changes on Linux and Windows endpoints.

05

Lateral Movement

Simulated SMB/RDP connections between lab VMs to identify anomalous authentication and network flows.

06

Data Exfiltration

Generated outbound traffic patterns to practise detecting unusual volume or destination anomalies.

06. Key Takeaways

What I Learned

Building this lab gave me end-to-end exposure to SOC operations. I learned how telemetry flows from endpoints to a SIEM, how rules turn raw logs into alerts, and how analysts prioritise and investigate those alerts.

The most valuable lesson was understanding the difference between noise and signal: without tuning, a SIEM generates overwhelming alerts. Effective detection requires knowing your environment, your assets and your adversaries.

  • Deployed a complete SIEM stack from scratch
  • Correlated events across Windows and Linux systems
  • Created custom detection rules for lab-specific scenarios
  • Practised incident triage and documentation
  • Understood the MITRE ATT&CK mapping of common alerts
