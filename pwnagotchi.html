Pwnagotchi Build

A self-contained, embedded Linux wireless security lab for passive WiFi monitoring, handshake capture and hands-on RF analysis.

Raspberry Pi Bettercap Linux Wireless Security RF Analysis
01. Overview

What is a Pwnagotchi?

Pwnagotchi is an AI-like, passive WiFi sniffer built on a Raspberry Pi. It uses Bettercap to listen for WiFi beaconing, deauthentication and handshake packets, then stores them for offline analysis. It is an excellent learning platform for wireless protocols, RF behaviour and 802.11 frame analysis.

This project was built in a fully isolated lab environment to understand how wireless networks advertise themselves, how handshakes are captured, and how those captures can be analysed ethically for defensive awareness.

Ethical Use Only

This device was used exclusively on networks I own or in isolated lab environments. Capturing traffic on networks without explicit authorisation is illegal in most jurisdictions.

03. Architecture

How It Works

1

Scan

Pwnagotchi scans for nearby 802.11 WiFi access points and clients using the onboard WiFi adapter.

2

Capture

It passively listens for WPA/WPA2 handshake packets and records them to local storage.

3

Analyse

Captured handshakes are transferred to a Kali Linux VM for inspection with Wireshark or Hashcat.

4

Learn

Findings are documented to understand wireless attack vectors and improve defensive detection.

04. Tasks Performed

What I Did

01

Firmware Installation

Downloaded the official Pwnagotchi image, verified its integrity, and flashed it to the MicroSD card using Raspberry Pi Imager.

02

Bettercap Configuration

Tuned Bettercap settings for channel hopping, whitelist management and handshake capture parameters in the lab.

03

Plugin Setup

Configured plugins for auto-update, grid peer tracking, session logging and display customisation.

04

Handshake Capture

Tested WPA2 handshake capture against my own isolated access point to validate the build and understand 4-way handshake structure.

05

Packet Analysis

Exported .pcap files to Wireshark and analysed EAPOL frames, beacon frames and deauthentication patterns.

06

Documentation

Documented the build process, configuration files and lessons learned for future reference and portfolio use.

05. Key Takeaways

What I Learned

802.11 Frame Structure

Deepened understanding of management, control and data frames in WiFi networks.

Handshake Mechanics

Learned how WPA2 4-way handshakes work and why they are valuable for offline analysis.

RF Behaviour

Observed how signal strength, channel congestion and nearby devices affect capture success.

Linux Embedded Systems

Gained practical experience configuring headless Raspberry Pi devices over SSH.
